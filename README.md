# AI Handwerk Wu

## Project Structure

.
├── backend
├── frontend
└── package.json
```

## Installation

### Backend

```bash
cd backend
npm install
```

### Frontend

```bash
cd frontend
npm install
```

## Run Development Server

### Backend

```bash
cd backend
npm run dev
```

### Frontend

```bash
cd frontend
npm run dev
```

## Run from Project Root

You can also use the root scripts:

### Start Backend

```bash
npm run dev:backend
```

### Start Frontend

```bash
npm run dev:frontend
```

### Start Both

```bash
npm run dev
```

## Build

### Backend

```bash
npm run build:backend
```

### Frontend

```bash
npm run build:frontend
```
